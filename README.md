# Кольорові ряди — пробна гра для iPhone

Статичні файли гри для пробної гри в Safari. Корінь сторінки — актуальна версія; попередня лежить в `archive/`.

| Де | Версія | Походження |
| --- | --- | --- |
| корінь (`/`) | Райдужна смужка від 4000 очок (2–4 клітинки; шанс 20% на придатний ряд, до трьох на 20 рядів) поверх молотка, історії партій і збережень, 13 файлів | `rainbow-d6dc18844b`, 200 тестів, вихідний проєкт `codex/rainbow-trial` `d29a8d5` |
| `archive/trial-f0203c018d/` | Попередня проба: баланс після 3000 очок і підказка протягом партії, 7 файлів | `trial-f0203c018d`, 128 тестів |

Усі сторінки цього акаунта на `github.io` мають спільне сховище браузера, тож збережена партія й рекорд спільні з `gameofyear-web`.
