# Кольорові ряди — пробна гра для iPhone

Статичні файли гри для пробної гри в Safari. Корінь сторінки — актуальна версія; попередні лежать в `archive/`.

| Де | Версія | Походження |
| --- | --- | --- |
| корінь (`/`) | Райдужна клітинка очищає будь-який повний ряд, також змішаний; захищене збереження партії й журналу (правила 2, 13 файлів) | `rainbow-8b400d4828`, 210 тестів; ті самі файли, що в `gameofyear-web`; джерело — `codex/rainbow-mixed-clear` приватного репозиторію |
| `archive/rainbow-d6dc18844b/` | Райдужна смужка від 4000 очок (джокер 2–4 клітинки; шанс 20% на придатний ряд, до трьох на 20 рядів); ряд очищається, коли всі звичайні клітинки одного кольору | `rainbow-d6dc18844b`, 200 тестів |
| `archive/trial-f0203c018d/` | Проба з балансом після 3000 очок і підказкою протягом партії, 7 файлів | `trial-f0203c018d`, 128 тестів |

Усі сторінки цього акаунта на `github.io` мають спільне сховище браузера, тож збережена партія й рекорд спільні з `gameofyear-web`. Нова збірка зберігає партію під ключами `kr.game.hammer.v2` і `kr.journal.hammer.v2`, старіші збірки їх не бачать.
